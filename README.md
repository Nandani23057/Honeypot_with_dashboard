# 🛡️ Cowrie Honeypot — Cybersecurity Monitoring Dashboard

### A Real-Time SSH Honeypot Monitoring and Attack Analysis Project

**Cowrie Honeypot Dashboard** is a cybersecurity project designed to capture, monitor, and visualize unauthorized SSH login attempts and suspicious attacker activity in a controlled environment.

Built using **Cowrie, Python, Streamlit, Pandas, and Plotly**, this project transforms honeypot logs into an interactive web dashboard, helping security enthusiasts and researchers understand attacker behavior, analyze login attempts, and investigate commands executed during simulated SSH sessions.

The dashboard features a unique **Old Photograph–inspired color palette**, combining vintage cream, beige, gray, and olive tones to create a clean and distinctive security monitoring interface.

## 🚀 Features

- **SSH Honeypot:** Uses Cowrie to simulate a vulnerable SSH service and capture interactions.
- **Security Monitoring Dashboard:** Displays collected honeypot events through a web interface.
- **Attack Analytics:** Analyzes login attempts, source IP addresses, attacker commands, and session activity.
- **Interactive Visualizations:** Uses Plotly charts to explore attack patterns.
- **Log Analysis:** Processes Cowrie JSON logs using Python and Pandas.
- **Custom UI Design:** Features a vintage-inspired color palette for a distinctive dashboard appearance.
- **Browser Accessibility:** Allows access to the dashboard from another device on a trusted local network.

## 🎯 Project Objectives

The primary objective of this project is to gain practical experience in honeypot deployment, cybersecurity monitoring, SSH attack analysis, log processing, and security dashboard development.

It demonstrates how raw security events can be transformed into meaningful visual insights for cybersecurity research and learning.

## 🔐 Security Notice

This project is intended for **educational purposes, authorized security research, and controlled lab environments only**. The dashboard should be restricted to a trusted network, and sensitive honeypot logs or captured credentials should never be published publicly.
